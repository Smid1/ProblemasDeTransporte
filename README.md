# ProblemasDeTransporte
Tarefa para a disciplina de Otimização Combinatória. Resolver pelos métodos do canto noroeste, custo mínimo e VAM.

# Tarefa:
Faça um programa em C ou Python que receba uma matriz N x N, vinda de um problema de transporte equilibrado e calcule (e mostre) a solução pelo método do canto noroeste, método do custo mínimo e método de VAM.

Entregue o código fonte com comentários do que foi feito em cada etapa e instruções para compilação e execução.

## Instruções de compilação e execução
1. Abra o terminal e navegue até a pasta onde o arquivo do programa está salvo.
2. Execute o comando para compilar:
``` bash
gcc program.c -o "nomeDoArquivoExecutavel"
```
3. Após compilar, execute o programa:
``` bash
./"nomeDoArquivoExecutavel"
```

O programa solicitará a entrada dos dados do problema. Sendo eles:
1. Número de origens
2. Número de destinos
3. Matriz de custos
4. Ofertas
5. Demandas

Em seguida, será calculado a solução em cada um dos métodos solicitados.
